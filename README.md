# # 🎴 My DISC Souvenir Card Generator

เว็บแอปพลิเคชันหน้าเดียว (Single File Web App) สำหรับสร้างการ์ดของที่ระลึกสะท้อนตัวตนตามโมเดล **DISC (4 ธาตุ)** ให้ผู้เข้าร่วมกิจกรรมกรอกข้อมูลส่วนตัว อาชีพ และเป้าหมาย พร้อมแปลงผลลัพธ์เป็นการ์ดกราฟิกสวยงามและดาวน์โหลดเป็นภาพความละเอียดสูง (.PNG) ได้ทันที

---

## ✨ ฟีเจอร์หลัก (Features)

* **Simple 1-Page Workflow:** กรอกแบบฟอร์มสั้นๆ แล้วกดสร้างการ์ดได้ในหน้าเดียว ไม่ต้องโหลดหน้าใหม่
* **DISC Theming (4 ธาตุ):** เปลี่ยนธีมสี ไอคอน และของตกแต่งอัตโนมัติตามบุคลิกภาพ DISC:
  * 💧 **S (Steadiness - ธาตุน้ำ):** โทนสีฟ้า อ่อนโยน รับฟัง สงบสุข
  * 🔥 **D (Dominance - ธาตุไฟ):** โทนสีแดง/ส้ม มุ่งมั่น ลุย ตัดสินใจไว
  * 🌬️ **I (Influence - ธาตุลม):** โทนสีเหลือง/อบอุ่น สดใส สร้างสรรค์ มิตรภาพ
  * 🌱 **C (Conscientiousness - ธาตุดิน):** โทนสีเขียว ละเอียด มีแบบแผน มั่นคง
* **High-Quality Export:** ส่งออกการ์ดเป็นไฟล์ภาพ `.png` ด้วยความละเอียดระดับ HD (Scale x3) ผ่านไลบรารี `html2canvas` เหมาะสำหรับแชร์โซเชียลหรือนำไปปรินต์
* **Responsive & Clean Design:** ออกแบบด้วยโทนสีมินิมอล ฟอนต์ Prompt อ่านง่าย รองรับการใช้งานทั้งบนมือถือและคอมพิวเตอร์

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **HTML5 / CSS3:** โครงสร้างเว็บและการตกแต่ง (Flexbox, CSS Variables, Gradients)
* **Vanilla JavaScript:** จัดการ DOM และ Event Handling พื้นฐาน (ไม่ต้องใช้ Framework)
* **Google Fonts:** ฟอนต์ [`Prompt`](https://fonts.google.com/specimen/Prompt) (Regular, Medium, Semi-bold, Bold)
* **html2canvas (v1.4.1):** ไลบรารีสำหรับจับภาพ DOM Element แปลงเป็น Canvas และบันทึกเป็นรูปภาพ

## 🚀 วิธีการติดตั้งและใช้งาน (Getting Started)

เนื่องจากโปรเจกต์นี้เป็นไฟล์ Standalone HTML ไม่จำเป็นต้องติดตั้ง Node.js หรือรันคำสั่ง Build:

1. **บันทึกโค้ด:**
   บันทึกโค้ดไว้ในไฟล์ชื่อ `index.html`

2. **เปิดใช้งาน:**
   ดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดบนเว็บเบราว์เซอร์ (Chrome, Edge, Safari หรือ Firefox) หรือเปิดผ่าน Extension เช่น **Live Server** บน VS Code

3. **ขั้นตอนการสร้างการ์ด:**
   * กรอกชื่อเล่น, อาชีพ/บทบาทปัจจุบัน และความตั้งใจในการร่วมกิจกรรม
   * เลือกโมเดล DISC ที่ตรงกับสไตล์ของตนเอง
   * กดปุ่ม **"ออกการ์ดของฉัน ✨"**
   * ตรวจสอบความถูกต้อง แล้วกดปุ่ม **"บันทึกรูปภาพ 📥"** เพื่อดาวน์โหลดไฟล์ PNG เข้าสู่เครื่อง
